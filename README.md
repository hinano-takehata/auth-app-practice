# auth-app-practice

## 概要
COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
Laravel Fortifyを使ったログイン・ログアウト・ユーザー登録機能と認証が必要なダッシュボードを作成しました。

## 使用技術
- PHP 8.5.10
- Laravel 10.50.4
- Laravel Fortify（認証）
- MySQL

## 学んだこと
- Laravel Fortify を使ったユーザー登録・ログイン・ログアウトの仕組みを学びました。
- auth ミドルウェアを使うことで認証されていないユーザーは入れないようにするルートの保護の仕方を学びました。
- ログインのダッシュボードと未ログイン時のログインページにリダイレクト設定を学びました。

## 動作確認
ブラウザで　http://localhost/register
にアクセスし、ユーザー登録フォームが表示されることを確認した。
ユーザー情報を入力し、登録ボタンをクリックし、登録が完了しダッシュボードに遷移することを確認した。
ログアウトボタンをクリックし、ウェルカムページにリダイレクトされることを確認した。
http://localhost/login
にアクセスし、ログイン画面が表示され、登録されたメールアドレスとパスワードでログインし、ダッシュボードに遷移することを確認した。
